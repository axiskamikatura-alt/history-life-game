# Ver.2.0 段階開発計画

## 第1段階・調査と復元

既存機能：Node.js標準サーバー、ES Modules、18章53選択肢、8項目の暮らし図鑑、簡易双六、localStorage、個人史出力。外部ランタイム依存なし。

旧版は `/workspace/history-life-backups/hitoyo-v1-before-v2.zip` へGit情報・画面例も含めてバックアップ。隣接manifestのSHA-256とZIPからの読み出しを照合。復元は別フォルダへ展開して内容を確認してから行う。実装中の作業を無条件に上書きしない。

変更計画：
1. 保存処理をstorage.jsへ分離。v1キーを読み取り移行し、旧キーを保持。v2キーの壊れたデータで旧版を黙って復元しない。段階ごとにスナップショット。
2. data/people.jsとlife.jsで出生環境・性格・家族・関係を扱う。乱数種は保存し、再読み込みによる結果の引き直しを避ける。幸福度は資産・身分に連動させない。
3. data/history.jsに史実・創作・参考情報を分け、年表と時代背景画面を用意する。日別気温や裏付けのない人口実数は出さない。
4. data/challenges.jsとchallenge.js、avatar.jsを追加。人生選択に従属する4回の挑戦、双六の駒移動。軽量SVG・CSS、外部画像なし。
5. economy.jsとdiary.js、結果・家計・日記画面。収支はゲーム内の仮定を明示、現代換算は任意の仮定に基づく参考試算で史料上の価格とは分ける。

## 画面

ホーム／出生設定（出自・名前・進行速度）／人生（プロフィール・場面・選択・結果・挑戦）／人物図鑑／暮らし図鑑／並行年表／時代背景／家計・日記／総括。小画面ではプロフィール詳細を折りたたむ。既存導線・図鑑・双六・ダウンロードを維持。

## 実装の境界

江戸のみ。他時代のコンテンツ、世代交代、公開、決済、外部接続は対象外。時代ID付きデータセットと共通エンジンを維持する。原則として性格・職業・関係の条件はイベントのルールとしてデータ化する。

進行速度は選択を代行しない。じっくり＝結果と背景を詳しく読む、標準＝結果を手動で進める、高速＝重要でない章の選択後結果だけを自動送り。重要章・挑戦・最後の章は必ず手動。自動送りは画面移動・中止で解除する。

検証：既存版の回帰、全選択肢・2出自の完走、保存移行と不正データ、乱数再現、遅延効果、親密度・家族・性格、各チャレンジの境界、家計収支の照合、画面幅320/390/768/1440。各段階を動く状態で保存。

## 未検証範囲

Windows、iOS Safari、iPadOS、Android実機はこの環境にない。Chromiumの画面幅・タッチ設定による確認と実機検証を区別する。史料調査・監修が済んでいない暮らし・物価・気候は仮設定または参考情報と明示する。
