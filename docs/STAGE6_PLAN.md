## 動作と学習設計

1. 人生の選択が完了してlogに入った最大年までを解放。次の章に移動しただけでは新年代を解放しない。ログが空なら学習問題は出さない。
2. 1回最大3問。「未回答を学ぶ」「間違えた問題を復習」「学んだ範囲をもう一度」。誤答は後で正解するまで復習対象。
3. 1問ずつ回答・正誤・理由・誤答補足・人生とのつながりを示す。高速でも自動で回答・次へは進めない。
4. 回答確定前に正解を表示しない。回答後は再クリックで回数を増やさない。問題途中・解説途中・セッション完了を保存する。中断しても人生へ戻れる。
5. 学習は任意。正誤で人生の資産・健康・幸福度を増減しない。学習履歴はこの人生に保存。新しい人生ではリセットし、暮らし図鑑は既存どおり残る。
6. 江戸後期のみ。他時代の出題は対応する時代データの追加後。中学歴史の重要語句と社会の変化を題材にした自主問題で、教科書・入試問題を複製せず、検定・監修済み教材とは称さない。
7. 記憶問題だけでなく、飢饉と生活の関係、条約の区別、時間順序、創作の人生と史実の線引きを扱う。参考機関は調査の入口として明示し、未実施の資料照合を済んだと偽らない。
