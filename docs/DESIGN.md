# 江戸編の基本仕様と今後の拡張

企画書（2026年10月19日）を基にした、ブラウザ版MVP。

## 今回の範囲

仮称「ひとよ」。日本橋界隈・江戸近郊、1800〜1860年。町人か近郊農家に生まれ、5歳から60歳まで18の節目をたどる。誕生時点の家庭は開始画面で設定し、選択は5歳から始める。60歳を迎えた時点で物語を閉じる。

指標は健やかさ・蓄え・学び・つながり。0〜100の抽象値で、実貨幣や病気・寿命を再現しない。指標がゼロでも進行不能にしない。選択を確定すると結果を表示し、次の季節への操作を分けて誤操作を防ぐ。結果は即時に保存する。二重の選択では数値を加算しない。

家族関係は伴侶・仲間との助け合い・一人の暮らし。仕事は商い・職人・農と行商。最終的な指標の特色を振り返りの見出しに使うが、勝敗や総合点は置かない。時代背景は折りたたみ説明と最終年表で確認できる。

双六は人生の11歳の章で必ず解放可能。6回以内に12マスを進む簡易ルール。出目は1〜6、あがりを越えたら到着。人生の指標には影響しない。歴史的な盤・ルールの再現ではなく、絵双六から着想を得た創作。

図鑑8項目は選択によって解放。進行保存は1人生分、図鑑は累積。端末内のlocalStorageを使用し、データが不正な場合はホームからやり直せる。新しい人生を始める前には、進行中データの置き換えを確認する。完成した人生はテキストに出力できる。

## 後の時代追加

時代データ・イベント・図鑑・遊びを独立させ、registry.jsに時代IDで登録する構造。ゲームの選択・進行・保存検証のロジックはDOMから独立させる。新しい時代の追加時には開始画面の時代選択、時代向け紹介・風景、時代別の保存枠や旧保存との移行も設計する。江戸編を別時代の数値や説明で上書きしない。

イベントの必須条件：年齢は昇順、選択肢は2つ以上、効果は既存指標のみ、歴史年は背景データに対応、解放項目は図鑑に存在。新しい分岐や特殊ルールにはエンジンのテストとブラウザの完走テストを追加する。

世代交代は後続段階。次世代に残すもの（家の記録・図鑑）と引き継がないもの（個人の健康など）を分けて設計する。100〜200年の展開を既存18章へ無理に混ぜない。

## 考証・公開に残ること

歴史的事件の大枠と、個人の架空の暮らしを分けて表示した。具体的な教育、修業、献立、住居、身分・性別による制約は未監修の仮設定。歴史資料の該当箇所を調査し、考証者の確認後に説明を更新する。参考機関へのリンク表記は個別設定の証明ではない。

表示幅の検証はChromiumのエミュレーション。実際のiOS Safari、Android端末、タブレット実機での操作や読みやすさ、対象ユーザーの10〜15分プレイ時間は今後のユーザーテストで確認する。公開・決済・外部サービス接続はユーザーの事前承認が必要。
